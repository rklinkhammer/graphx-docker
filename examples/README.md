# GraphX examples

- `shared-memory`, `udp-unicast`, `udp-broadcast`, and `udp-multicast` demonstrate
  individual transports.
- `mixed-network`, `macvlan`, `ipvlan-l2`, and `ipvlan-l3` demonstrate semantic
  profiles on the shared system-OVS lab.
- `network-observability` demonstrates declarative SPAN capture and bounded faults.
- `static-route-policy` demonstrates namespaces, routes, nftables, and manual route
  activation.
- `sdr-node` demonstrates simulated and external-device data planes.
- `qemu-node/tap` demonstrates QEMU TAP networking through OVS.

Use each directory's launcher and README. Privileged examples require Linux or the
GraphX Lima guest.

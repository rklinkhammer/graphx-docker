# GraphX 1.1.0 release license inventory

This inventory covers software shipped in, linked by, or used to produce the
GraphX 1.1.0 native archives, release OCI images, web application, telemetry
service, and QEMU Buildroot guest. It records upstream declarations; it is not
legal advice and does not replace the collected license texts or artifact-bound
SBOMs.

## Authoritative evidence

| Scope | Evidence |
| --- | --- |
| GraphX sources and native archive | `LICENSE`, `THIRD_PARTY.md`, and each native release SPDX 2.3 document |
| Runtime and telemetry OCI images | Per-platform BuildKit SPDX attestations attached to each immutable image digest |
| Telemetry and web dependencies | `apps/telemetry/package-lock.json` and `web/package-lock.json` |
| QEMU guest and its toolchain | Buildroot `output/legal-info/manifest.csv`, `host-manifest.csv`, and collected license/source directories |

The QEMU legal bundle is generated by `examples/qemu-node/scripts/build.sh` at
`examples/qemu-node/output/legal-info`. The directory is ignored because it
contains generated source archives and license copies. Preserve that bundle with
any distributed QEMU images.

in an SPDX document; retain `NOASSERTION` and consult the license files installed
in the pinned image or the relevant upstream package record. The release's
per-platform BuildKit attestations, rather than this summary, are authoritative
for exact package membership.

## Reproduction commands

```sh
# Native package SBOM and license-bearing archive
python3 scripts/release/build_release.py \
  --build-dir build/release-local \
  --output-dir outputs/release-local \
  --tag v1.1.0

# QEMU images plus target/host manifests and collected legal material
examples/qemu-node/scripts/build.sh

# Local OCI review; release attestations remain authoritative
docker build --build-arg GRAPHX_VERSION=1.1.0 \
  --tag graphx-license-audit-runtime:1.1.0 --file Dockerfile .
docker build --build-arg GRAPHX_VERSION=1.1.0 \
  --tag graphx-license-audit-telemetry:1.1.0 \
  --file docker/telemetry.Dockerfile .
docker scout sbom --format spdx local://graphx-license-audit-runtime:1.1.0
docker scout sbom --format spdx local://graphx-license-audit-telemetry:1.1.0
```
